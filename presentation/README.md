# Presentation Materials

This folder contains the documentation and scripts required for the final presentation of the "Adversarial Attacks on ASR" project.

## Files Included:
1.  **presentation_guide.md**: A script for the 10-15 minute presentation, including an agenda, demo instructions, and expected outcomes.
2.  **Q&A_common.md**: A curated list of common questions and answers, categorized by technical depth.
3.  **README.md**: This file.

## How to Use:
1.  **Run the Demo**: Before presenting, ensure the live demo (`src/demo/live_transcribe.py`) is working on your laptop.
2.  **Print/Display**: You can display the PDF versions of the presentation files if provided, or use the markdown text to create slides in PowerPoint/Google Slides.
3.  **Rehearse**: Read through the `presentation_guide.md` to get the timing right. The live demo is the centerpiece of the presentation.

## Tips:
-   Start with the **Clean Demo** first to establish a baseline.
-   Then, switch to **Adversarial Demo** to show the corruption.
-   If you have the **Targeted Attack** working, show the "Magic" moment where a neutral phrase becomes "aai590".

Good luck with your presentation!
